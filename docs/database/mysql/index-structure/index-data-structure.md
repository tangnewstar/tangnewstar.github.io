# 索引数据结构

底层数据结构有两种：**B+树** 和 **哈希表**。

### B+树索引

是一种平衡多路树，**最主流的索引结构**（InnoDB和MyISAM默认）。

- 叶子节点：存储数据，且由相邻链表连接形成有序链表。适合范围查询。
- 非叶子节点：不存储数据，只存储索引结构，用于快速定位叶子节点。

优势：范围查询，排序，适合大量数据（1000万层数3到4，仅需3-4次IO），联合索引。

适用：多数查询场景，范围查询、排序、联合条件查询。

### 哈希索引

基于哈希表实现，通过hash函数将key映射到哈希桶。仅Memory引擎默认支持，InnoDB仅支持**自适应哈希**。

- 键值通过hash函数计算存储位置，查询高效定位
- 不支持有序存储，哈希值无序

优势：等值查询极快，查询复杂度接近于O(1)。

劣势：范围查询，排序，联合索引的部分匹配不支持；哈希冲突（链表）。

适用：频繁等值查询。
