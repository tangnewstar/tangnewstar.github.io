# Spring Transactional

多个事务方法相互调用时，事务如何在这些方法之间传播？新建事务还是加入现有事务？

`@Transactional（propagation = xxx)`

### REQUIRED（默认）

当前存在事务，则加入事务；否则创建一个新事务

### REQUIRES_NEW

无论当前是否存在事务，都创建一个新的事务，且新事务与原有事务完全隔离。（原有事务被挂起，直到新事务完成）

*用于需要独立事务的场景（日志记录）*

### SUPPORTS

如果当前存在事务则加入事务；如果没有事务以非事务方式执行（无事务）

*可选事务（查询操作，有事务无事务都可以）*

### MANDATORY

必须在已有事务执行，若当前没有事务，抛出IllegalTransactionStateException

*强制要求调用方开启事务（核心业务）*

### NOT_SUPPORTED

以非事务方式执行，若当前存在事务，则将其挂起直到方法执行完恢复

*明确不需要事务（性能敏感的查询）*

### NEVER

必须以非事务的方式，若存在当前事务，抛出`IllegalTransactionStateException`

*严格禁止在事务中执行的操作（异步任务）*

### NESTED

如果当前存在事务，则在嵌套事务中执行（嵌套事务是原有事务的一部分，仅在原有事务内独立回滚）；如果当前没有事务，则创建新事务（同`REQUIRED`）
