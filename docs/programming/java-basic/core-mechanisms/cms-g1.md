# CMS & G1

### CMS

基于标记-清除算法

初始标记（STW） → 并发标记 → 重新标记（STW）→ 并发清除

- 初始标记：阻塞用户线程，标记GCROOTS关联的对象
- 并发标记：和用户线程并行，GCRoot Tracing
- 重新标记：阻塞用户线程，并发标记阶段对象引用修改（标记变化）需要重新标记

优势：并发收集，停顿时间短，适合对延时敏感的服务

劣势：内存碎片问题（没有整理），对CPU资源敏感（并发），无法处理浮动垃圾（并发标记阶段产生）

### G1

基于标记-整理算法 

基于Region的内存分配，只回收垃圾比例最高的Region

初始标记（STW） → 并发标记 → 最终标记（STW） → 筛选回收（STW）
